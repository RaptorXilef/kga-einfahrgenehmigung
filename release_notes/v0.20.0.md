Manuelle Ausstellung so einfach wie noch nie:

- **Der Universal-Generator:** Im Reiter "Ausstellung" können Vorstandsmitglieder nun in 4 übersichtlichen Schritten manuelle Genehmigungen (z.B. für Barzahler vor Ort) ausstellen.
- **Gutscheincodes erstellen:** Genauso einfach lassen sich hier Rabatt-Codes erstellen.
- **Flexible Preissteuerung:** Sie können beim Ausstellen nun jederzeit wählen, ob der Preis automatisch berechnet wird, ob die Genehmigung komplett kostenlos ist (0,00 €) oder ob Sie einen abweichenden Sonderpreis (Manuell) eintragen möchten.
