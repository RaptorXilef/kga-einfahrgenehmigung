- **Smarte Seitenblätter-Funktion:** Alle Tabellen im Dashboard haben nun Seiten (1, 2, 3 ...). Sie können selbst einstellen, ob Sie 10, 25, 50 oder 100 Anträge pro Seite sehen möchten. Das macht das System selbst bei tausenden Anträgen blitzschnell.
- **Echtzeit-Suche:** Die Suchleiste wurde an das neue Seiten-System angepasst und durchsucht in Sekundenbruchteilen die gesamte Datenbank nach Pächtern, Codes oder Kennzeichen, während Sie tippen.
- **Kennzeichen-Automatik:** Das System erkennt nun amtliche deutsche Kennzeichen schon bei der Eingabe und formatiert sie vollautomatisch richtig (aus "bhd123" wird z.B. "B-HD 123").
