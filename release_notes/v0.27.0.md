Das Fahrzeug-Kategorie System wurde massiv flexibilisiert:

- **Freie Fahrzeug-Wahl:** Das System ist nicht mehr fest auf "PKW" und "LKW" beschränkt, sondern unterstützt im Hintergrund beliebig konfigurierbare Fahrzeugtypen (z.B. Car-Sharing, Entsorgung).
- **Historische Daten gerettet:** Wenn Sie in der Zukunft einen alten Fahrzeugtyp aus dem System löschen, bleiben historische Anträge in den Statistiken unter "Ehemalig" dennoch korrekt erhalten, sodass Ihre Jahresabschlüsse immer exakt stimmen.
- **Einheitlicher Look:** Das Design der Kennzeichen-Schilder wurde über alle Dashboard-Tabs hinweg vereinheitlicht.
