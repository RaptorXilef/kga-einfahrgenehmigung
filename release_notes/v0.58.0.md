Das System arbeitet nun im Hintergrund noch eigenständiger:

- **Automatisches Update-System:** Das interne Update-System wurde durch eine vollautomatische Lösung im Hintergrund ersetzt. Das System hält sich nun von selbst aktuell, ohne dass Sie manuell ZIP-Dateien herunterladen oder Knöpfe drücken müssen.
- **Sicheres Daten-Management:** Die technischen Wege, wie das System Daten aktualisiert und speichert, wurden grundlegend modernisiert, um Fehler bei zukünftigen Erweiterungen auszuschließen.
