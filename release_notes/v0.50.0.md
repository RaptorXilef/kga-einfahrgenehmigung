Die manuelle Zuordnung von Bank-Dateien wurde stark vereinfacht:

- **Live-Vorschau:** Der Bank-Abgleich hat einen neuen Assistenten bekommen. Wenn Sie im erweiterten Modus eine CSV-Datei hochladen, zeigt Ihnen das System nun sofort eine Live-Vorschau der echten Buchungszeile an.
- **Fehlerfreie Zuordnung:** So können Sie die Spalten für Betrag und Verwendungszweck noch einfacher, sicherer und fehlerfrei zuordnen.
