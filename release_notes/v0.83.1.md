# 🚗 Smarte Kennzeichen, Anti-Spam & echte LKW-Ausnahmen

In diesem Update dreht sich alles um das Herzstück der Genehmigungen: Die KFZ-Kennzeichen. Die Eingabe ist nun intelligenter, blockiert gezielt Quatsch-Eingaben und nimmt euch viel Formatierungsarbeit ab.

## 🌟 Highlights & neue Funktionen

* **Schluss mit Müll-Eingaben:** Das System verlangt nun zwingend eine plausible Kombination aus Buchstaben und Zahlen. Phantasie-Eingaben wie "XXXXX", "TEST" oder "unbekannt" werden konsequent blockiert. Das hält die Datenbank sauber und verhindert ungültige Genehmigungen.
* **Wiederhergestellte Auto-Formatierung:** Wer faul ist und "BXX123" eintippt, bekommt vom System vollautomatisch ein schönes "B-XX 123" formatiert. Dabei habe ich direkt einen Fehler behoben, der 4-stellige Buchstabenkombinationen (wie HDAB123) bisher an der falschen Stelle getrennt hat.
* **Internationale & Besondere Kennzeichen:** Egal ob eurasische, rumänische, kyrillische Kennzeichen oder klassische deutsche H-Zulassungen - das System erkennt sie nun alle problemlos. Auch der automatische Bank-Import filtert diese internationalen Formate jetzt fehlerfrei aus den Kontoauszügen heraus.
* **LKW & Car-Sharing wirklich optional:** Wenn das Kennzeichen bei Lieferanten oder Car-Sharing-Fahrzeugen im Formular weggelassen wird, bastelt das System im Hintergrund keine störenden Platzhalter mehr hinein. Das Feld bleibt stattdessen einfach sauber leer. Außerdem wurde ein Fehler Behoben, der dafür gesorgt hat, dass bei Lieferfahrzeugen ein Kennzeichen angegeben werden musste, obwohl dies als Optional markiert war.
