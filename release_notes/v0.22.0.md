Eine schöne Wartungsseite und eine Erleichterung für E-Mail-Empfänger:

- **Die Wartungsseite (Maintenance Mode):** Während wir Updates einspielen, sehen Ihre Pächter fortan keine Fehlermeldungen mehr, sondern eine freundliche "Kurze Pause!" Seite. Administratoren können sich weiterhin einloggen.
- **6-stellige Kurzcodes:** Manche E-Mail-Programme machen Links unklickbar. Pächter können ihren E-Mail-Posteingang nun auch ganz einfach durch das Eintippen eines großen, 6-stelligen Codes (z.B. A8F9Z2) bestätigen.
