Die digitalen Türsteher wurden massiv aufgerüstet:

- **Tagesaktueller Spam-Schutz:** Das System blockiert Wegwerf-E-Mails nun anhand einer Liste, die sich einmal pro Woche vollautomatisch im Hintergrund selbst aktualisiert.
- **Automatische IP-Sperre:** Wenn von einem Gerät zu viele fehlerhafte Anträge in kurzer Zeit gestellt werden, blockiert das System diese Verbindung nun automatisch für 15 Minuten, um das Formular vor Spam-Angriffen zu schützen.
- **Striktere E-Mail-Prüfung:** Das System prüft nun noch tiefergehend, ob die Domain einer angegebenen E-Mail-Adresse überhaupt existiert und E-Mails empfangen kann, bevor der Antrag zugelassen wird.
