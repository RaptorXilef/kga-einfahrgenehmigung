Backups & Daten-Wiederherstellung leicht gemacht:

- **Backup Dashboard:** Es gibt im Admin-Bereich nun einen eigenen, übersichtlichen Tab für Datensicherungen (Backups).
- **Granulare Wiederherstellung:** Falls Sie sich jemals verklickt haben, können Sie aus alten Backups nun ganz gezielt einzelne Dinge (z.B. nur die Benutzer oder nur die Gutscheine) wiederherstellen.
- **Automatische Ersteinrichtung:** Bei der Installation auf einem völlig neuen Server richtet das System seine Datenbanktabellen ab sofort vollautomatisch selbst ein (Zero-Touch Installation).
