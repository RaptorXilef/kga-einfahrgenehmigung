Präzisere Steuerung für das Berechtigungs-System:

- **"Verbot schlägt Erlaubnis":** Wenn einem Vorstandsmitglied ein Recht generell erlaubt, aber im Detail verboten wurde (z.B. "Darf Finanzen sehen, aber nicht als bezahlt markieren"), überschreibt das Verbot ab sofort immer die Erlaubnis. Das macht die Rechte-Matrix absolut kugelsicher.
- **Live-Rechte:** Das System wurde umgebaut, sodass geänderte Rechte sofort wirksam werden, ohne dass eine Pause oder ein Caching-Fehler entsteht.
