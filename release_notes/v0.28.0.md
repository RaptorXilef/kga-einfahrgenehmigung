Willkommen in der neuen Sicherheitszentrale! Die Rechteverwaltung wurde revolutioniert:

- **Die Rechte-Matrix:** Superadmins können die Befugnisse anderer Vorstandsmitglieder nun über eine interaktive Schalter-Matrix bis ins allerkleinste Detail steuern.
- **Visuelles Feedback:** Wenn Sie einem Admin ein "Über-Recht" geben, leuchten die darin enthaltenen "Unter-Rechte" automatisch grün auf.
- **Experten & Fokus-Ansicht:** Sie können die Ansicht nun wechseln, um entweder alle Rechte zu sehen, oder alles auszublenden, was das jeweilige Vorstandsmitglied ohnehin nicht darf.
