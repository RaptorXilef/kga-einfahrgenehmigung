Schluss mit versehentlichen Doppelbuchungen:

- **Die Kollisions-Prüfung:** Das System prüft ab sofort in Echtzeit, ob eine Parzelle in einem gewählten Zeitraum bereits eine Genehmigung besitzt oder gerade ein anderer Nachbar für denselben Tag einen Antrag ausfüllt. Ist dies der Fall, wird der Antrag blockiert und der Nutzer gewarnt. Das verhindert Streit an der Schranke.
- **Das E-Mail-Protokoll:** Im Dashboard sehen Administratoren nun ein transparentes Logbuch über alle Mails, die das System verschickt hat. So können Sie Pächtern immer belegen, wann die Rechnung verschickt wurde.
