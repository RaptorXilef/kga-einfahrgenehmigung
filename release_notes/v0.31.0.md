Ein Turbo für das öffentliche Antrags-Formular:

- **E-Mail-Warteschlange (Mail Queue):** Bisher musste der Pächter beim Klick auf "Absenden" warten, bis der Server die E-Mails tatsächlich an ihn und den Vorstand verschickt hatte (Lade-Kreis). Das wurde geändert! E-Mails werden nun asynchron in eine Warteschlange gelegt und rasend schnell im Hintergrund verschickt.
- **Erfolgsseite optimiert:** Nach einem erfolgreichen Antrag wird das Formular nun komplett ausgeblendet, damit niemand aus Versehen doppelt klickt. Die automatische Weiterleitung wurde auf angenehme 15 Sekunden verlängert.
