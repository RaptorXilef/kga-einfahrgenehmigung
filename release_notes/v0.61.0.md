Dieses Update bringt massive Erleichterungen für die Kassenwarte:

- **Einfacher Bank-Import:** Der Bank-Abgleich ist nun idiotensicher. Im neuen "Einfachen Modus" reicht es, die CSV-Datei hochzuladen – das System verarbeitet und verbucht alle passenden Zahlungen vollautomatisch in Sekundenbruchteilen, ohne zusätzliche Klicks!
- **Intelligentes Mahnwesen:** Das System kann nun automatische Zahlungserinnerungen verschicken. Dabei achtet es auf eine "Schonfrist" (Cooldown), damit säumige Pächter nicht mit täglichen E-Mails überflutet werden.
- **Aufgeräumtes Dashboard:** Wartungs- und Backup-Werkzeuge haben nun übersichtliche, dedizierte Reiter erhalten.
- **Profi-Backups:** Datensicherungen werden nun platzsparend als ZIP-Datei gepackt. Bei Bedarf können sie direkt auf einen externen Server (FTP) gespiegelt werden.
