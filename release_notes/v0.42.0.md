Das System bringt nun ein noch intelligenteres Update-Verfahren mit:

- **Sichere 2-Phasen-Updates:** Wenn Sie das System künftig per Knopfdruck aktualisieren, nutzt es ein neues 2-Phasen-Modell. Es tauscht erst die Dateien aus und passt danach vollautomatisch die Datenbankstrukturen an. So wird sichergestellt, dass bei Updates niemals Daten verloren gehen.
- **Transparenz:** Nach jedem Update sehen Administratoren nun ein detailliertes Protokoll, welche Datenbank-Anpassungen im Hintergrund durchgeführt wurden.
